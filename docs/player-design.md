# 李志 · 叁叁肆 个人音乐播放器 — 产品设计文档

## 一、项目概述

**主题**：以歌手李志（叁叁肆巡演发起人）为核心的个人音乐播放器主页
**架构**：Web 网页端 + 桌面客户端（Tauri/Electron）
**开发策略**：前端优先，数据写死（Mock），后端后续接入
**技术栈建议**：
- Web：React 18 + Vite + TailwindCSS + HTML5 Audio/Video API
- 客户端：Tauri（轻量，推荐）或 Electron
- 状态管理：Zustand / Redux Toolkit
- 歌词解析：自定义 LRC Parser
- 音频可视化：Web Audio API (AnalyserNode)

## 三、播放器系统（核心）

### 3.1 基础控制
- ▶️ 播放 / ⏸ 暂停
- ⏮ 上一首 / ⏭ 下一首
- 🔄 进度条拖拽定位（带时间提示）
- 🔊 音量滑块 + 静音切换
- 🔁 播放模式：列表循环 / 单曲循环 / 随机播放
- 📋 播放队列管理（拖拽排序、移除、清空）

### 3.2 歌词系统
- LRC 格式解析，逐行高亮
- 平滑滚动动画
- 点击歌词行跳转到对应时间点
- 在线/离线歌词切换
- 歌词字体大小调节
- 桌面歌词悬浮窗（客户端专属）

### 3.3 增强功能
- ⏱ 定时关闭（15/30/60分钟/播完当前）
- 🎚 倍速播放（0.75x / 1x / 1.25x / 1.5x）
- 🎵 音质切换（标准/高品质/无损，UI预留）
- 🌊 音频可视化（频谱波形动画）
- 🖼 封面大图模式（沉浸式播放器）
- 📱 迷你播放器（底部常驻 + 可拖拽悬浮球）
- ⌨️ 快捷键（空格暂停、上下切歌、左右快进退）
- 📤 分享功能（生成当前播放卡片图）

### 3.4 播放状态持久化
- 刷新页面自动恢复播放队列和进度
- 记忆上次播放位置（localStorage）
- 最近播放历史（最多100条）

## 五、交互与视觉设计方向

### 风格关键词
- 暗色系为主（深灰/藏蓝），辅以暖色点缀
- 南京城市元素（城墙、梧桐、街道）
- 手绘/插画风格封面
- 简洁留白，文艺气质
- 微动画：页面切换、卡片悬浮、播放进度

### 响应式
- Desktop：1920/1440/1280 三档适配
- Tablet：768~1024
- Mobile：≤767（底部Tab导航 + 迷你播放器常驻）

## 六、数据结构设计（Mock）

```typescript
// 歌曲
interface Song {
  id: string;
  title: string;
  album: string;
  albumId: string;
  duration: number;        // 秒
  cover: string;           // 封面URL
  audioUrl: string;        // 音频URL
  lyrics: string;          // LRC文本
  bpm: number;
  key: string;             // 调性 如 "G"
  capo: number;            // 变调夹位置
  tags: string[];          // 标签
  playCount: number;
  releaseYear: number;
}

// 专辑
interface Album {
  id: string;
  name: string;
  cover: string;
  releaseDate: string;
  type: 'studio' | 'live' | 'ep' | 'single';
  songIds: string[];
  description: string;
}

// 视频
interface Video {
  id: string;
  title: string;
  cover: string;
  videoUrl: string;
  duration: number;
  category: 'live' | 'mv' | 'documentary' | 'behind';
  relatedSongId?: string;
  description: string;
}

// 吉他谱
interface ChordSheet {
  songId: string;
  title: string;
  difficulty: 1 | 2 | 3 | 4 | 5;
  capo: number;
  originalKey: string;
  bpm: number;
  chords: ChordDiagram[];
  sections: ChordSection[];
}

// 赞助等级
interface SponsorTier {
  id: string;
  name: string;
  price: { monthly: number; yearly: number };
  benefits: string[];
  color: string;
  icon: string;
}
```
